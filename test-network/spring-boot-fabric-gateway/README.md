# Hyperledger Fabric Spring Boot Gateway Demo

This sample uses the Fabric Gateway Java client to talk to the local Docker Compose network in `test-network` and execute read/write chaincode transactions.

For a step-by-step setup and API walkthrough, see the [Spring Boot Gateway guide](../guide.html).

## Prerequisites

- Docker with Compose enabled
- Fabric binaries and Docker images installed in the parent `fabric-samples` directory
- Java 17+
- Maven 3.8+

## Start the Fabric network

From the `test-network` directory:

```bash
cd /path/to/fabric-samples/test-network
./network.sh up
./network.sh createChannel -c mychannel
./network.sh deployCC -c mychannel -ccn basic -ccp ../asset-transfer-basic/chaincode-go -ccl go
```

The network should expose the Org1 peer on `localhost:7051`.
`network.sh createChannel` configures the Org1 and Org2 anchor peers. If using a
channel created without anchor peers, configure them from `test-network` before
starting the application:

```bash
./scripts/setAnchorPeer.sh 1 mychannel
./scripts/setAnchorPeer.sh 2 mychannel
```

The default test-network endorsement policy requires both Org1 and Org2, and
the application requests endorsers from both organizations.

## Start the Spring Boot application

```bash
cd /path/to/fabric-samples/test-network/spring-boot-fabric-gateway
mvn spring-boot:run
```

The service listens on `http://localhost:9001`. Swagger UI is available at
`http://localhost:9001/swagger-ui/index.html`.

## Test the application

### Health check

```bash
curl http://localhost:9001/api/health
```

### Initialize the ledger

```bash
curl -i -X POST http://localhost:9001/api/assets/init
```

### List assets

```bash
curl http://localhost:9001/api/assets
```

### Create an asset

```bash
curl -X POST http://localhost:9001/api/assets \
  -H 'Content-Type: application/json' \
  -d '{
    "id": "spring-asset-001",
    "color": "green",
    "size": "5",
    "owner": "alice",
    "appraisedValue": "400"
  }'
```

### Read an asset

```bash
curl http://localhost:9001/api/assets/spring-asset-001
```

### Transfer an asset

```bash
curl -X PUT http://localhost:9001/api/assets/spring-asset-001/transfer \
  -H 'Content-Type: application/json' \
  -d '{
    "newOwner": "bob"
  }'
```

## Notes

- The sample uses the `Org1MSP` identity generated by `test-network`.
- The default connection targets `peer0.org1.example.com` through the local Docker-exposed port `localhost:7051`.
- If your network uses a different organization or channel name, override the values in `src/main/resources/application.properties` or with environment variables.
